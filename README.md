# Almasor Sales Dashboard

Rebuilt sales performance dashboard project, prepared for Google AI Studio iteration.

## Stack
- React + Vite
- Recharts
- Responsive dashboard layout

## Run locally
```bash
npm install
npm run dev
```

## Google AI Studio
Use this repository as the starting codebase when importing into Google AI Studio. The supplied Google Sheet was not directly accessible during this rebuild, so KPI values are clearly marked as a snapshot/sample and should be connected to the live sheet before operational use.

## Dashboard sections
- Overview KPIs
- Province performance
- Package mix
- Target progress
- SLI/J.O. overview

Source project archive was supplied in the conversation; this repo contains a new clean starter rebuild.
